    How to run this lab

    Easiest way: connect the board and press Start autopilot. It runs every test in Needs testing in an order that keeps walking to a minimum, starts and finishes each one itself, and spots breaths, soil dunks, floors and sun on its own. When it needs your hands it chimes, says the instruction out loud and sends a Mac notification; press Done or the space bar once you've done it. Sun tests wait for a forecast UV index of 1 or more. Everything autosaves to bench/runs/.

    The cards below still work by hand if you want to drive a test yourself.

    • Start test stamps the clock. Grey Mark buttons stamp the moment you do each physical step, so press them as you act, not after.
    • Only one test runs at a time. Finish freezes the result and its data. Reset clears it to redo.
    • Pass limits are bench judgment set from the datasheet and our first runs. Where a limit is the datasheet's own number it says so.
    • Conditions refresh every 10 minutes and the station reading is frozen into each test when you finish it.
    • Results stay in this browser across reloads. The raw stream does not: Save raw stream into bench/runs/ before closing.
    • The RS485 probe is not in the board's stream yet, so this lab covers the STEMMA soil sensor only. Calibration lives in soil-cal.html.
